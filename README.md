# Mises a jour DOSTUDIO

Ce depot public contient uniquement les informations de version et les liens de mises a jour de DOSTUDIO. Le code source du logiciel reste dans son depot prive.

Le fichier latest.json est consulte automatiquement par DOSTUDIO 0.2.1 et les versions suivantes. Le programme propose une notification lorsqu'une version stable plus recente est annoncee ; il n'installe rien sans intervention de l'utilisateur.

La version 0.2.1 constitue la reference initiale. Ce depot ne contient pas encore d'installateur public. Pour chaque prochaine version, publier le telechargement teste et ses notes, puis modifier latest.json avec le nouveau numero et le lien HTTPS permanent. Ne pas y placer de secrets ou de liens prives temporaires.
